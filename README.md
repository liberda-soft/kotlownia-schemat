# Kotłownia – schemat

Interaktywny model 3D ściany instalacji kotłowni (2 × 2,5 m): pompa ciepła alpha innotec SWC 170H, zasobnik c.w.u. Sunex FISH S15 300, dolne źródło (glikol), obieg pompy ciepła ze sprzęgłem hydraulicznym, c.o. domu i woda użytkowa. Każdy element ma opis, parametry, przykładowe modele i pozycję na liście zakupów; jest też schemat hydrauliczny.

- `index.html` – ściana instalacji
- `zasobnik.html` – zasobnik z przekrojami

Three.js 0.170 z CDN, bez budowania – wystarczy dowolny serwer plików statycznych.
